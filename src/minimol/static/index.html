After a key, the new group becomes the target, so keys can be chained: on methane, 11o adds two carbons and turns the last one into OH (ethanol); 3 on a CH₃ makes it a phenyl and targets the para carbon. Moving the mouse picks a new target.

Mouse & keys
  • 2D / 3D: toolbar switch or Tab. 2D is a skeletal drawing with implicit hydrogens; switching to 3D builds the structure and relaxes it
  • Rotate (3D): left-drag on empty space. In 2D, left-drag on empty space selects
  • Pan: right-drag or Shift+drag
  • Zoom: mouse wheel / pinch
  • Draw: click empty space for a new atom; click an atom to grow a bond (replaces an H if the atom is full); drag from an atom to place one, or onto another atom to bond them; click an atom of another element to change it; click a bond to cycle single/double/triple
  • Delete: right-click an atom or bond (Draw or Delete tool), or click it with the Delete tool
  • Select: Ctrl+drag a box (Ctrl+Shift+drag adds); Ctrl+click toggles one atom; with the Select tool, click (Shift adds). 2/3/4 atoms show distance/angle/dihedral
  • Clipboard: Ctrl+C / Ctrl+X / Ctrl+V copy, cut and paste structures (with ChemDraw too; see the README for formats)
  • Keys: Ctrl+R optimize (3D) or clean up (2D), Ctrl+Z / Ctrl+Shift+Z undo/redo, Del delete, Ctrl+A select all, Esc clear selection, R reset view
